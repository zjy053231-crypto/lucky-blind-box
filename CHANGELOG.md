# Changelog · 更新日志

All notable changes to this project are documented here. Format follows Keep a Changelog; versions follow Semantic Versioning.
本项目的所有重要变更都记录于此。格式遵循 Keep a Changelog，版本号遵循语义化版本。

## v0.1.7 — 2026-11-23

- **Thicker tab icons / 导航图标加粗** — Increased the stroke width of the three bottom-nav SVG icons for better legibility on small screens. 底部三个导航 SVG 图标描边加粗，提升小屏辨识度。
- **Fully bilingual docs / 文档全面双语** — README rewritten as English-first, Chinese-second throughout; added this bilingual CHANGELOG. README 全文改为英文在前、中文在后的对照排版；新增本双语更新日志。

## v0.1.6 — 2026-11-22

- **Live demo on GitHub Pages / GitHub Pages 在线演示** — The app is now playable at the repo's Pages URL; homepage field and a "Live Demo" badge point to it. 应用现可在仓库的 Pages 地址直接体验；仓库 homepage 与 Live Demo 徽章均指向该链接。
- **Social sharing meta / 社交分享元信息** — Added Open Graph and Twitter Card tags so shares show title, description and preview image. 加入 Open Graph / Twitter Card 元信息，分享时显示标题、描述与预览图。
- **PWA-friendly / PWA 友好** — Theme color and full-screen web app meta; "Add to Home Screen" opens it full-screen. 主题色与全屏 Web App 元信息，「添加到主屏幕」后全屏打开。

## v0.1.5 — 2026-11-20

- **Metadata sync / 元信息同步** — Bilingual repository description, license holder and README badges aligned with the released package. 仓库双语简介、许可持有人与 README 徽章与发布包保持一致。

## v0.1.4 — 2026-11-20

- **Click feedback / 点击反馈** — Ripple, jelly bounce and sparkle burst on every tap; browser-synthesized sounds and mobile vibration; a mute toggle in the top bar (saved locally). 每次点击有水波涟漪、果冻回弹与星光迸发；浏览器合成音效与手机震动；顶栏静音开关（本地保存）。
- **Narrow-screen fix / 窄屏修复** — Top bar tightened so the wallet and language switch never overflow at 360/320px. 顶栏收紧，钱包与语言切换在 360/320px 下不再溢出。

## v0.1.3 — 2026-11-20

- **Stronger dynamic background / 动态背景强化** — Twinkling stardust, corner sparkles, meteors and expanding ripples; bubbles raised to 18 and paw prints to 6. 闪烁星尘、四角星光、流星与扩散水波；气泡增至 18、爪印增至 6。
- **Bilingual description / 双语简介** — Repository description written English-first, Chinese-second. 仓库简介改为英文在前、中文在后。

## v0.1.2 — 2026-11-20

- **Dynamic background / 动态背景** — Flowing gradients, breathing glows and drifting paw prints on a layer beneath the content; disabled under "reduce motion". 流动渐变、呼吸光晕与漂移爪印，位于内容层之下，系统开启「减少动效」时关闭。

## v0.1.1 — 2026-11-20

- **Three languages / 三语** — Simplified / Traditional / English switch, with an embedded Simplified→Traditional map to stay dependency-free. 简体 / 繁體 / English 切换，内嵌简繁映射表以保持零依赖。

## v0.1.0 — 2026-11-19

- **First release / 首发** — Local gacha meal picker with rarity tiers, ticket economy, custom pool, streak check-in and meal cards; single HTML file plus launchers for macOS and Windows. 本地抽卡选餐，含稀有度、饭票经济、自定义卡池、连续打卡与三餐卡片；单 HTML 文件，附 macOS / Windows 启动器。
